A personal learning project: instead of only using databases, I built a small one from scratch in Go.
The goal was not to make a product, but to understand what happens underneath, how information is
organized in memory and on disk and how it is found quickly.

## What I learned

- How to organize data with the right data structures so it can be stored and searched efficiently.
- How a database works internally, beyond writing queries.
- The Go language: its way of structuring programs, handling errors and working with files.
