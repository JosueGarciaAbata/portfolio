A personal learning project: instead of only using databases, I built a small one from scratch in Go.
The goal was never to make a product, but to understand what happens underneath, how information is
organized and how it can be found quickly.

Working through it taught me how the right data structure makes storing and searching efficient, how a
database works internally beyond writing queries, and how Go approaches program structure, error handling
and working with files.
